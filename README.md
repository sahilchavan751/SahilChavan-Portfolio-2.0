# Sahil Chavan | Creative Developer Portfolio 2.0 🚀

A modern, highly interactive, and visually striking portfolio built to showcase a multi-disciplinary approach to digital creation. This portfolio seamlessly blends **coding, video editing, UI/UX design, and 3D animation** into a single cohesive experience.

## ✨ Key Features
- **Cinematic Animations:** Powered by GSAP and ScrollTrigger for buttery-smooth, scroll-scrubbed image sequences and reveal effects.
- **Modern UI Aesthetics:** Features glassmorphism panels, floating interactive elements, custom cursors, and sleek dark mode typographies.
- **Magazine-Style Layouts:** Dynamic, highly responsive grids displaying selected works across various creative disciplines.
- **Next.js Optimized:** Fully optimized routing, image loading, and component structures leveraging the latest React and Next.js capabilities.
- **Mobile First Adjustments:** Custom media queries ensuring pixel-perfect layout and readability on smaller devices without sacrificing aesthetic quality.

## 🛠 Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Language:** TypeScript
- **Styling:** Custom CSS (with extensive CSS variables and media query tuning)
- **Animation:** [GSAP](https://gsap.com/) (GreenSock Animation Platform) + ScrollTrigger
- **Deployment:** Vercel

## 📂 Project Structure Overview
The portfolio is divided into several immersive sections and pages:
- **Home (`/`):** The main landing page featuring a scroll-reactive profile, brand logo clouds, tools ecosystem, and a curated project grid.
- **Visual Design (`/visual-design`):** Interface engineering and UI/UX projects.
- **Editing (`/editing`):** Video editing and post-production portfolio with a specialized split-screen frosted glass layout.
- **Color Grade (`/color-grade`):** Color science and cinematic grading works.
- **Photography (`/photography`):** High-contrast, cinematic photography captures.
- **Contact (`/contact`):** A beautiful bento-box grid layout housing all professional correspondence links (Email, Location, Phone, Socials).

## 🚀 Running Locally

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sahilchavan751/SahilChavan-Portfolio-2.0.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd SahilChavan-Portfolio-2.0
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```
   *(Note: This project relies on `node_modules` which are not tracked in Git to save space.)*

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **View in browser:**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
